# Data Science & AI Portfolio

**Statistics · Machine Learning · Financial Analytics**

호서대학교에서 통계학·데이터 분석·머신러닝을 공부하며, 금융·산업·공공 분야의 문제를 데이터로 분석하고 해결하는 프로젝트를 수행하고 있습니다. 금융 시계열과 퀀트 리서치에 관심을 두고 개인 연구를 이어가고 있습니다.

**Tech Stack:** Python · pandas · NumPy · Jupyter · scikit-learn · Streamlit · JavaScript · Git
